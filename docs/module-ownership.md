# Module Ownership

## Common foundation

- Authentication
- Users and roles
- Institutions
- Shared database conventions
- API conventions
- React layout/shared components
- Seed/demo data
- Local setup scripts

## Training & Learning domain

- Training ERP
- LMS
- Assessment
- Skills
- Credentials

## Careers & Intelligence domain

- Careers
- Employers
- Skill matching
- Training intelligence
- Analytics

## Rule

A module is complete only when its database model, FastAPI API, frontend screens, business logic, seed/demo data, and end-to-end flow work together.
