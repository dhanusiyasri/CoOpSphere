# Skills-03 — Skill Gap & Learning Recommendations

## Scope
Connect the Skills-02 competency passport to existing published Training ERP courses and published Careers opportunities.

## Trainee
- View skill gaps below working proficiency (3/5).
- See matched published learning recommendations.
- See matched published employment opportunities.
- See skills to build next for each job match.

## Manager
- Select a trainee within the existing Skill Passport role scope.
- View the same grounded recommendations.

## API
- GET `/api/v1/skills/recommendations/my`
- GET `/api/v1/skills/recommendations/{trainee_id}`

No database migration is required.
